# Gmarket Sans

이 디렉터리의 Gmarket Sans OTF 파일은 Gmarket 공식 배포본입니다.

- 공식 안내: https://corp.gmarket.com/fonts/
- 원본 패키지: https://corp.gmarket.com/fonts/GmarketSansOTF.zip
- 라이선스: SIL Open Font License 1.1 (`GmarketSans-OFL.txt`)

Gmarket 공식 안내에 따르면 개인과 기업이 영리·비영리 목적으로 사용할 수
있습니다. 폰트 파일을 재배포할 때에는 저작권 및 라이선스 정보를 함께
제공해야 합니다.
