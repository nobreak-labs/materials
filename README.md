# Materials

슬라이드와 문서에서 공통으로 사용하는 폰트 및 이미지 자료를 관리합니다.

## 디렉터리 구조

```text
assets/
├── fonts/   # 폰트 원본과 라이선스
└── images/  # 배경, 삽화 등 외부에서 참조하는 이미지
```

## 사용 안내

- 폰트 파일은 `assets/fonts/`에 추가합니다.
- 이미지 파일은 `assets/images/`에 추가합니다.
- 폰트를 추가할 때는 배포 조건을 확인하고 라이선스 파일을 함께 보관합니다.
- 폰트의 출처와 버전 등 상세 정보는 [`assets/fonts/README.md`](assets/fonts/README.md)를 참고합니다.
